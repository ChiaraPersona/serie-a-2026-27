## Integrazione manuale

Usare ID canonico e percorso locale esatto. Inserire la verifica in data/sources/team-pages/player-photo-approvals.json: playerId, localPath, sha256, status VERIFIED, evidence, verifiedAt, verifiedBy, license, attributionText e attributionUrl. Il digest lega la verifica al file: una modifica richiede nuova verifica. Preferire WebP proporzionati e leggeri per nuovi file autorizzati; non duplicare né sovrascrivere gli originali. Eseguire node scripts/build-player-photo-registry.cjs. Nessun abbinamento solo per nome. In caso di più squadre per lo stesso ID, vedere conflicts in inventory.json.
